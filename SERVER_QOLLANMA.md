# Dars Jadvali - Local Server Ishga Tushirish

## 1-usul: START_SERVER.bat faylini bosing

Eng oson usul - `START_SERVER.bat` faylini ikki marta bosing. Server avtomatik ishga tushadi.

## 2-usul: Terminal orqali

1. Terminal oching va shu papkaga o'ting:
   ```
   cd "f:\my school website\boysun-im-timetable"
   ```

2. Serverni ishga tushiring:
   ```
   python app.py
   ```

3. Brauzerda oching:
   - Asosiy sahifa: http://127.0.0.1:5000
   - Admin panel: http://127.0.0.1:5000/admin-login.html
